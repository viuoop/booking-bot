# Бот онлайн-записи в салон

Telegram-бот на aiogram 3: клиенты записываются к мастерам, админ салона настраивает мастеров, услуги и часы работы, мастера получают уведомления и расписание.

## Что умеет

- **Клиент:** выбирает мастера, услугу, день и время (показываются только свободные слоты), оставляет имя и телефон. В «Мои записи» можно отменить или перенести запись. За 24 часа и за 2 часа до визита приходит напоминание с кнопками «Приду» / «Отменить».
- **Админ** (`/admin`): мастера, услуги, часы работы, исключения (закрыть день или часы, открыть выходной), записи по дням, отмена записей. `/export` — xlsx со всеми записями, `/stats` — статистика за 7 дней.
- **Мастер:** привязывается по одноразовой ссылке, получает уведомления о новых, отменённых и перенесённых записях. `/start` показывает его записи на сегодня и завтра. Каждый день в 20:00 (Киев) приходит расписание на завтра, если записи есть.

## Настройка

1. Создайте бота у @BotFather, возьмите токен.
2. Скопируйте `.env.example` в `.env` и заполните:

```
BOT_TOKEN=токен_от_BotFather
ADMIN_IDS=123456789,987654321
DEMO_MODE=
```

- `BOT_TOKEN` — токен бота (обязательно).
- `ADMIN_IDS` — Telegram ID админов салона через запятую (узнать свой можно у @userinfobot). Нужны в обычном режиме.
- `DEMO_MODE` — `1` включает демо-режим (см. ниже), пусто — обычный.

## Запуск

```
uv sync
uv run bot.py
```

База — файл `booking.db` рядом с ботом (создаётся сам). Время хранится в UTC, показывается по Киеву.

## Первые шаги в /admin

1. `/admin` → **Мастера** → **Добавить**, введите имя мастера.
2. В карточке мастера: **Услуги** → добавить (название, длительность, цена). Мастер виден клиентам, только когда у него есть хотя бы одна услуга.
3. **Часы** — для каждого дня недели введите `10:00-18:00` или «Выходной». Без часов слотов нет.
4. **Привязать Telegram** — бот выдаст одноразовую ссылку `t.me/<бот>?start=m_...`. Мастер открывает её со своего аккаунта и становится привязанным (ссылка после этого перестаёт работать).
5. Готово: клиенты пишут боту `/start` и записываются.

## Демо-режим

При `DEMO_MODE=1` у каждого пользователя своя песочница: свой салон с тестовыми мастерами, а он сам — админ этого салона (`/admin`). Можно показывать бота потенциальным клиентам, не затрагивая реальные данные. `ADMIN_IDS` в демо-режиме не используется.

## Тесты

```
uv run pytest
```

Telegram-сценарии на живом боте проверяются вручную: привязка мастера по ссылке, уведомление мастеру, напоминание (создайте запись на «через 2 ч 5 мин» и подождите), кнопка «Приду» (в `/admin` у записи появится ✅).
